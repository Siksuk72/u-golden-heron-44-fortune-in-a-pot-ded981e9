One fortune for the houseplant on the windowsill, for Fortune in a Pot
on make.fun. A new leaf is coming, the sun has already chosen the
plant's best side, and its keeper will brag about it to guests: a
prediction in fortune cadence, a warm image that only fits a plant in
a window, and a kind twist — the plant is so loved that its keeper
shows it off. No doom, no withering, no mockery; just good news for a
little green one.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (UTF-8, 1–120 characters).
